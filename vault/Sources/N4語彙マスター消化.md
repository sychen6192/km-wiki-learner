# N4語彙マスター消化

> 來源：Raw/ 內兩份 PDF（U11–U15 基礎語彙與 U11–U20 實戰演練）

**一句話總結**：集中涵蓋日檢 N4 核心語法結構（被動／使役、條件與相對修飾、文脈推論）與生活應用場景（日常作息、學習方法、職場基礎），為從基礎到進階的過渡教材。

## 重點

- **語法軸心**：U11–U15 強化動詞變形與文型接續（～てしまう／～てみる／～ようにする）；U11–U20 實戰演練引入條件式（～たら／～ば／～なら）、被動使役態、以及長句拆解技巧。
- **主題語彙分層**：按場景切割為「日常習慣」、「學習策略」、「職場互動」與「抽象形容」。強調同義替換與語境微差（如：わかる vs 理解する）。
- **實戰應用**：演習部分以閱讀測驗與完形填空為主，訓練在有限時間內鎖定關鍵助詞與文型的能力。

## 對本 vault 的意義

這篇來源支撐了語言學習領域的「可理解輸入」假說（[[Krashen's Input Hypothesis]]），並為 [[Japanese N4 Grammar Patterns]] 提供具體教材依據。透過拆解長句與場景分類，可直接轉換為複習卡片與 [[Maps/Japanese Language|日本語領域 Map]] 的內容架構。原始檔 `Raw/N4語彙マスター_6_語彙_U11_U15.pdf` 與 `Raw/N4語彙マスター_8_語彙_実践演習U11_U20.pdf` 僅供查證，永不修改。
