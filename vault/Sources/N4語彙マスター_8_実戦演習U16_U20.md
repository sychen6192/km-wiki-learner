# N4語彙マスター U16–U20

> 來源：[[N4語彙マスター_8_語彙_実践演習U11_U20.pdf]]

本組教材為 JLPT N4 詞彙實戰練習，聚焦日常生活與校園常見情境的「詞彙辨義」與「慣用搭配」。與 U11–U15 的主題分類不同，本單元以選擇題為主，大量測試詞彙在具體語境中的正確用法與同義替換。

## 核心收錄範圍
- **Q1 情境選詞**：聚焦校園與生活基礎動名詞（`参加する`、`書類`、`翻訳する`、`入学式`、`規則`）與節日/家庭用語（`あつまる`）。考點在於區分近義動詞或精確匹配情境。
- **Q2 同義換裝**：測試 N4 基礎敬語與口語的對等轉換。核心對照組包含：「通知 → `伝える`」、「接受 → `もらう`」、「詢問 → `聞く`」、「道謝 → `ありがとう`」。此為閱讀解題的關鍵橋樑。
- **Q3 詞彙正確用法**：針對易混淆多義詞設計誘答。重點區分：
  - `紹介`（必須接「人」，不可接事）
  - `世話`（照顧/打點日常事務）
  - `承知`（正式場景的同意與理解確認）
  - `中止`（取消既定計劃或活動）
