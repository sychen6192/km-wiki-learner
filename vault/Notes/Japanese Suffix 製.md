# Japanese Suffix 製

**〜せい（製）** 是接尾詞，用於名詞後表示「材質」或「產地」。在 N4 階段需熟記其與助詞 `で`、`に` 的取捨差異。

## 接續規則
- 接於**名詞**後：`木材 + 製` → 木製（もくせい）
- 接於**國籍/地名**後：`日本 + 製` → 日本製（にほんせい）

## 核心辨析：〜製 vs 〜で / 〜に
| 用法 | 意義 | 例句 |
|---|---|---|
| **〜製** | 強調「製造地」或「成品材質」 | 木製のいすを買いました。｜日本製のテレビ。 |
| **〜で作る** | 強調「原料材質」（被加工過程） | 木材で机を作ります。 |
| **〜に作る** | 強調「製作地點」 | ここでパソコンを作っています。 |

## N4 試題常見陷阱
- 題目常給 `木〇〇のドア`，正確接續為 `もくせい`（選填材質），而非 `で作られた`（語意重複）。
- 輸出/輸入貿易單元中，`〜製` 會作為產品標籤頻繁出現，需與 `原料／材料` 區分：前者是成品屬性，後者是生產要素。
