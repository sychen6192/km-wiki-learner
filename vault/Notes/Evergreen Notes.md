# Evergreen Notes

**Evergreen notes** 是 Andy Matuschak 提出的筆記形態：筆記不是一次性的會議紀錄或閱讀摘要，而是**跨專案、跨時間持續演化的概念單位**。這座維基的每一篇 `Notes/` 都以此為目標。

四個特徵：

1. **原子性（atomic）** — 一頁只講一個概念，標題就是那個概念本身，讓 `[[標題]]` 可以像變數名一樣被引用。
2. **概念導向** — 依概念組織，而非依來源或時間；同一本書的十個想法應該是十頁，不是一頁書摘。
3. **稠密連結** — 每頁至少連向兩個相關概念；寫連結的動作會逼你想清楚概念之間的關係，這是 [[Zettelkasten]] 傳統的核心洞見。
4. **持續改寫** — 筆記有生命週期。本維基用 `status` 欄位標記：`seed`（佔位）→ `budding`（有骨架）→ `evergreen`（可長期引用）。

在 [[LLM-Native Wiki]] 裡，evergreen 概念被機器放大：LLM 可以不知疲倦地把 seed 養成 evergreen，而人類只需在 [[Spaced Repetition]] 的複習裡驗收品質、修剪方向。
