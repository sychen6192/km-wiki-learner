# Japanese Suffix ために

**〜のために** 在 N4 層級具備雙向功能：表「目的（為了...）」與表「原因／理由（因為...）」。兩者文法接續相同，但語境邏輯截然不同。

## 接續規則
- `名詞 + の +ために` → 表目的或原因
- `動詞辞書形/ない形 + ために` → 僅表「目的」或「必然結果」（非主觀意志可控制）

## 教材裡實際出現的用法：全部是「目的」
| 例句（逐句出自本課教材） | 接續 |
|---|---|
| 健康（けんこう）のために、毎朝（まいあさ）ジョギングを して います。 | 名詞 + の + ために |
| 海外（かいがい）の技術（ぎじゅつ）を知（し）るために、外国（がいこく）の言葉（ことば）を勉強（べんきょう）したいです。 | 動詞辞書形 + ために |
| 米（こめ）の技術を勉強する ために、日本（にほん）に来（き）ました。 | 動詞辞書形 + ために |

> ⚠️ `〜ために` 另有表「原因」的用法，但**本課教材沒有出現**——上面五處全是目的。
> 要練因果用法得另找素材，不要以為這課教過。

## N4 易混點與解題技巧
1. **目的 vs 理由**：若後面接「努力、勉強、準備」等意志動詞，多為目的；若接「病気になる、泣く、壊れる」等非意志結果，多為原因。
2. **て形式 ため**：教材中出現 `〜ために`（中顿形）可表示「為了...（而做前句動作）」或「因為...（導致後句結果）」。解題時務必檢視前後句主語是否一致、動詞是否具備意志性。
3. **與 ように 的對立**（一般 N4 知識，**非本課教材內容**）：目的句型常考 `〜ために` vs
   `〜ように`。前者強調「主動採取行動」，後者強調「希望達成某種狀態／藉助外力」。
   教材裡沒有 `ように`，這條請對照別的講義再確認。
