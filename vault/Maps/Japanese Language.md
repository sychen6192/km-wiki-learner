## Learning Path
語言學習不是背誦，而是模式識別。本領域按 [[Spaced Repetition]] 原則配置複習檔，並聚焦「文法結構 → 場景語彙 → 實戰拆解」的遞進關係。下一步將針對易混句型與助詞微差建立對比筆記，並補齊對應的閱讀素材。
